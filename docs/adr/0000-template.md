# NNNN: Decision title

- Status: Proposed
- Date: YYYY-MM-DD
- Roadmap: [Related milestone](../../ROADMAP.md)

Copy this file for a new architecture decision. Use the next available four-digit
number and a short filename that describes the decision. Use **Proposed** while
the decision is under discussion and **Accepted** once it has been agreed. If a
later ADR supersedes an accepted decision, update its status to **Superseded**
and link the replacement. Update the roadmap when an accepted ADR changes a
decision recorded there.

## Context

Describe the problem, the constraints, and the realistic alternatives. Explain
why a decision is needed now.

## Decision

State what the project will do and why this option fits the constraints.
Identify which milestone will implement it.

## Consequences

Record what the decision makes easier, what it costs, and what risks or follow-up
work it creates. Describe how the team will verify the decision when implemented.
